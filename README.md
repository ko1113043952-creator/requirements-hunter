# 需求猎手 🎯

> 把你的模糊想法，变成能直接交给 AI 执行的完整需求。

一个可以用在任意对话式 AI（DeepSeek、豆包、GPT、Claude 等）里的 Prompt Skill。通过系统性追问，帮你把「我想做个 XXX」打磨成结构清晰、可立即执行的需求文档和 Agent 提示词。

---

## ✨ 它能做什么

- 🔍 **自动识别**你的想法是模糊的还是具体的，调整追问策略
- ❓ **系统性追问**，每轮 3~5 个问题，每题附带推荐答案，你可以直接同意
- 🚫 **不放过模糊点**——「好看」「简单」「现代感」都会被追问具体含义
- ⚡ **随时叫停**——说「够了」或 `/done` 立刻输出结果
- 📄 **双格式输出**：结构化需求文档 + 可执行 Agent 提示词（纯文本 & XML 两种）
- 🌐 **语言智能匹配**——做中文产品就出中文提示词，不会整出英文网站

## 🚀 快速开始

### 方式一：System Prompt（推荐）

1. 复制 [`prompt.md`](./prompt.md) 的全部内容
2. 粘贴到 AI 的**系统提示词**位置：
   - **ChatGPT**：点击左上角头像 → Settings → Personalization → Custom instructions
   - **Claude**：新建 Project → Project instructions
   - **DeepSeek**：对话设置 → 系统提示
   - **豆包**：创建 AI → 系统提示词
3. 在对话框直接描述你的想法，需求猎手自动开始追问 ✅

### 方式二：User Message（随用随贴）

在任意 AI 对话框里发送：

```
请你扮演「需求猎手」，按以下规则工作：

[粘贴 prompt.md 的全部内容]

我的想法是：[你的想法]
```

## 🌱 小白版：写通知、周报、邮件这类日常文字活

[`prompt-beginner.md`](./prompt-beginner.md) 是给不懂技术的同事用的精简版，约 600 字：

- 每轮只问 3 个左右的问题，通常两轮问完
- 每题带选项、推荐和具体例子，回「1A 2B 3C」就行，拿不准的题回「按推荐」
- 问完先给一份「任务确认单」，你说「开始」它才动手写
- 不出需求文档和 XML，问清楚就当场把东西写出来

用法：复制 `prompt-beginner.md` 的全部内容，把最后一行的 `[写在这里]` 换成你想做的事，贴进任意聊天 AI 发送。

在豆包（2026 年 11 月）实测过。想把想法整理成需求文档再交给 Agent 执行的，请用完整版 `prompt.md`。

## 📖 使用示例

**用户输入：**
> 我想做一个记账 App

**需求猎手追问第一轮：**

❓ **Q1** - **目标用户**：这个记账 App 主要给谁用？
- A：个人用，管理自己的日常开销
- B：家庭用，多人共享账本
- C：小微企业用，管理经营流水

➡️ 推荐 A，个人记账需求最普遍，MVP 最容易验证。

❓ **Q2** - **核心记录方式**：用户怎么记一笔账？
- A：手动输入金额 + 选分类
- B：拍小票 / 截图，AI 自动识别
- C：语音输入

➡️ 推荐 A，开发成本低，用户习惯成熟，先跑通再加 AI 识别。

...（持续追问直到需求清晰）

**最终输出：需求文档 + Agent 执行提示词（两种格式）**

## 💡 设计理念

需求猎手基于 **grill-me** 的核心设计思想构建：
- 把需求视为一棵**决策树**，按层次解锁问题
- AI 负责找事实，用户负责做决策
- 每个问题都有**立场鲜明的推荐答案**，降低用户认知负担
- 追问到无死角，输出到可执行
